# حظر المكالمات المتكررة (CallBlocker) - الإصدار 2.0

## كيف يعمل
ترتيب فحص كل مكالمة واردة:
1. المفتاح السريع "تشغيل الحظر" متوقف ← تمرّ المكالمة.
2. الرقم في القائمة البيضاء ← تمرّ.
3. الرقم محفوظ في جهات الاتصال (إذا فعّلت الخيار) ← تمرّ.
4. الرقم في القائمة السوداء ← تُرفض دائماً بلا رسالة.
5. خارج ساعات التفعيل ← تمرّ.
6. وإلا: تمرّ المكالمات حتى العدد المسموح خلال المدة، وما زاد عنها يُرفض
   ويُرسل للمتصل SMS مرة واحدة في كل مدة.

## الميزات
- مدة الحظر وعدد المكالمات المسموحة قابلان للتعديل.
- ساعات التفعيل مع خيار "اليوم كله" (ويدعم الفترات التي تمتد بعد منتصف الليل).
- نص الرسالة قابل للتعديل، والكلمة {المدة} تُستبدل بوقت الانتظار تلقائياً.
- سجل بالمكالمات المحظورة (الرقم، آخر محاولة، العدد، السبب) مع زر للإضافة للقائمة البيضاء.
- إشعار عند كل حظر (اختياري).
- قائمة بيضاء (من جهات الاتصال أو يدوياً) وقائمة سوداء. إضافة رقم لإحداهما تزيله من الأخرى.

## البناء في Android Studio
1. File ← Open واختر مجلد CallBlocker.
2. انتظر Gradle Sync (يحتاج إنترنت أول مرة، ووافق على تثبيت SDK 34 إن طُلب).
3. وصّل الهاتف (USB debugging) واضغط Run، أو Build ← Build APK(s).

## أول تشغيل
اضغط "تفعيل الصلاحيات" ووافق على الرسائل وعلى جعل التطبيق تطبيق فرز المكالمات.
يعمل على أندرويد 10 (API 29) فما فوق.

## البناء بدون Android Studio (GitHub Actions)
1. أنشئ مستودعاً جديداً على github.com وارفع **محتويات** مجلد CallBlocker إلى جذر المستودع
   (بما فيها المجلد المخفي .github).
2. افتح تبويب Actions، وسيبدأ البناء تلقائياً (3 إلى 5 دقائق). يمكنك أيضاً تشغيله يدوياً بزر Run workflow.
3. بعد النجاح افتح تشغيل البناء ونزّل ملف CallBlocker-debug-apk من قسم Artifacts، وفك ضغطه.
4. انقل app-debug.apk إلى الهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة" إذا طُلب).
